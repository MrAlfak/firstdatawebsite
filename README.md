# First Data Website

Bilingual landing page for Avvalin Data / First Data.

## Stack

- Next.js 14
- React 18
- TypeScript
- CSS modules through the Next.js app router global stylesheet
- Ready for Vercel deployment

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Languages

- Persian: `/?lang=fa`
- English: `/?lang=en`

## Vercel settings

Use these settings when importing the repository in Vercel:

- Framework Preset: Next.js
- Build Command: `npm run build`
- Install Command: `npm install`
- Output Directory: `.next`
